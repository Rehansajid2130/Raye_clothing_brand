📦 How to Install & Use in React / shadcn Projects

The component files have already been added to this repository under components/kokonutui/activity-terrain.tsx and components.json.

Installation via shadcn CLI:

npx shadcn@latest add https://kokonutui.com/r/activity-terrain.json

Usage with your GitHub Repository Activity:

import ActivityTerrain from "@/components/kokonutui/activity-terrain"; import { fetchGitHubRepoActivity } from "@/lib/github-activity"; export default async function Page() { // Fetches live commits from Rehansajid2130/Raye_clothing_brand const { data, endDate } = await fetchGitHubRepoActivity( "Rehansajid2130", "Raye_clothing_brand", 140 // 20 weeks of daily contribution data ); return ( <ActivityTerrain data={data} endDate={endDate} title="Rayé Clothing Brand — Repository Activity" defaultFlat={false} /> ); }
